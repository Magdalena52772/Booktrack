# BookTrack 📚

**BookTrack** is an engineering thesis project: a web-based system designed to support the reading process and analyze user reading habits through a dedicated analytical dashboard.

## 🌟 Overview
The project integrates a web environment for readers with a specialized desktop administration tool for data analysis.

### Key Modules:
* **Authorization & User Management:** Role-based access control (User/Admin) using Django Auth.
* **Book Management:** Integration with **Google Books API** for metadata retrieval (titles, authors, covers).
* **User Dashboard:** Real-time progress tracking, including page counters and reading statistics (Chart.js).
* **Gamification System:** Implementation of 10 unique badges (e.g., "Bookworm", "Marathoner") using **Lazy Evaluation** to optimize database performance.
* **Admin Panel (PySide6):** A standalone desktop application for system management, data generation, and advanced analytics (Matplotlib/QtCharts).

## 🛠️ Tech Stack
* **Backend:** Python (Django, ORM).
* **Frontend:** Django Templates, Chart.js.
* **Desktop Application:** PySide6, Matplotlib.
* **External APIs:** Google Books API.
